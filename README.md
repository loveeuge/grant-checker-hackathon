# 지원사업 제출 전 체크리스트 MVP

지원사업 공고문, 팀 정보, 준비 서류 목록을 넣으면 **1페이지 제출 전 체크리스트**를 만들어 주는 해커톤 데모입니다. 결과는 자동 판단이 아니라 사람이 제출 전에 확인할 항목을 정리하는 보조 도구입니다.

## 아이디어

초기 팀은 공고문을 읽고 제출 서류, 자격 조건, 예산 제한, 개인정보 문구를 직접 대조해야 합니다. 이 MVP는 그 과정을 짧게 줄이기 위해 다음 입력을 받습니다.

- 지원사업 공고문 텍스트
- 팀 소개와 프로젝트 개요
- 현재 준비한 서류 목록

출력은 심사나 제출 대행이 아니라, "지금 빠진 것이 무엇인지", "공고문 원문과 다시 대조할 항목은 무엇인지", "개인정보와 안전 측면에서 멈춰야 할 지점은 어디인지"를 한 페이지로 보여주는 체크리스트입니다.

## OpenAI API Key 입력 방식

API key는 발표자 또는 운영 관리자가 로컬 실행 환경에만 입력합니다. 저장소, 샘플 데이터, 화면 캡처, 발표 자료에는 실제 key를 넣지 않습니다. 앱 화면의 관리자 패널에 입력하면 서버 메모리에만 보관하고 브라우저 저장소에는 남기지 않습니다.

로컬 환경 변수 방식:

```bash
export OPENAI_API_KEY="YOUR_OPENAI_API_KEY"
npm start
```

로컬 전용 `.env` 파일 방식:

```bash
OPENAI_API_KEY=YOUR_OPENAI_API_KEY
OPENAI_MODEL=gpt-5.4-mini
ADMIN_TOKEN=
```

주의:

- 실제 key를 `README.md`, `data/sample.json`, 화면 녹화, Git 커밋에 포함하지 않습니다.
- key 입력은 관리자 PC에서만 수행하고, 참가자나 심사위원에게 key 입력을 요청하지 않습니다.
- 데모용 샘플에는 가상 공고와 가상 팀 정보만 사용합니다.

## 오늘 만들 MVP 범위

- 가상 공고문, 가상 팀 정보, 준비 서류 목록을 입력합니다.
- OpenAI API로 1페이지 제출 전 체크리스트 초안을 생성합니다.
- 마감일, 누락 서류, 예산 제한, 데이터/개인정보 설명 필요 항목을 표시합니다.
- 결과를 "제출 전 사람이 확인할 목록"으로 보여줍니다.
- 해커톤 발표에서는 `data/sample.json` 기반 데모만 수행합니다.

## 오늘 제외 범위

- 실제 지원사업 접수 또는 제출 대행
- 실제 개인정보 저장, 장기 보관, 재사용
- 자동 합격/불합격 판단 또는 신청 자격 확정
- 기관 접수 시스템 로그인, 파일 업로드, 전자서명, 결제
- 법률, 회계, 세무 자문으로 해석될 수 있는 최종 판단

## 안전 원칙

- **가상 데이터 우선**: 데모에는 실제 이름, 연락처, 주민번호, 계좌번호, 사업자번호를 넣지 않습니다.
- **저장 최소화**: API key와 개인정보 원문은 저장하지 않는 것을 기본 원칙으로 둡니다.
- **사람 최종 검토**: AI 결과는 체크리스트 초안이며, 공고문 원문과 접수 시스템 양식은 사람이 확인합니다.
- **자동 판단 금지**: "지원 가능/불가능"을 단정하지 않고, 확인이 필요한 근거와 질문으로 표시합니다.
- **제출 기능 제외**: MVP는 제출 버튼을 만들지 않고, 실제 기관 시스템과 연동하지 않습니다.

## 해커톤 발표 포인트

- 문제: 마감 직전 서류 누락과 조건 오독이 초기 팀의 시간을 크게 잡아먹습니다.
- 해결: 공고문, 팀 정보, 서류 목록을 넣으면 제출 전 1페이지 체크리스트가 나옵니다.
- 차별점: 자동 합격 판단이 아니라, 제출 실수를 줄이는 안전한 보조 흐름에 집중합니다.
- 데모: 샘플 공고에서 개인정보 동의서와 예비창업 확인 자료 누락을 즉시 찾습니다.
- 확장성: 추후 기관별 양식 매핑, 팀별 진행 상태 저장, 협업 리뷰 기능으로 확장할 수 있습니다.
